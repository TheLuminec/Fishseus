🐟 Welcome

Fishseus is a modular voice-assistant stack for a motorized Billy Bass fish. Use the sidebar to configure audio capture, speech recognition, LLM, TTS, motor control, and the fish personality prompt. Chat lets you talk to Fishseus directly from the browser.

Memory & Context

Shown to the fish in full on every turn. Facts are saved when you ask it to remember something ("remember that…", "add to your memory…"), and you can add or fix them here. Labels are internal ids the fish uses to update or forget a fact.

📜 Conversation Memory

Every exchange is saved to data/conversation_log.jsonl. The fish recalls the ones inside the window below (highlighted), across restarts. To keep a conversation for good, say "remember this conversation" or use Save to Long-Term Memory: it's summarised into facts. Start Fresh makes the fish forget the conversation so far but keeps the log; delete a single exchange if it was misheard.

🔍 What the Fish Sees

Personality

Edit what the fish is told: its character and voice, the response rules, and the lines it falls back on. Changes apply on the next message, no restart needed.

📜 Character & Voice

Who the fish is and how it talks (config/personality_prompt.txt). The reply format, tool and memory rules are below, so editing this can't break them.

🧩 Rules & Other Prompt Text

Everything else the fish is told. Customised text is saved to config/prompt_texts.json; Reset restores the built-in default. Guidance and examples for each tool live on the Tools page.
